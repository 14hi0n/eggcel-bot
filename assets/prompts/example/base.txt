# Базовый промпт, который используется при каждой генерации.

Придумай короткую русскоязычную подпись для мема по изображению.
Учитывай персонажей, их эмоции, позы, действия и заметные детали изображения.
Не просто описывай картинку — добавь ей новый смешной контекст.
Подпись должна быть короткой, понятной и естественной.

Не объясняй шутку и не добавляй лишний текст.
